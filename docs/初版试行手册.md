# 初版试行手册（板卡到货后照此执行）

> 目标链路：PC Modbus 从站 ⇄ RS485 ⇄ Hi3861（OpenHarmony） ⇄ Wi-Fi/MQTT ⇄ 本机看板。
> 相关文档：`协议适配指南.md`、`寄存器映射表.md`、`../补充说明.md`（工程外改动与构建注意）。

## 0. 一次性准备（到货前完成）

1. **PC 侧环境 = 项目专属 venv**（Python 3.9，位于 `src\project\.venv`，不入 git）：

   ```powershell
   cd D:\hi3861_hdu_iot_application\src\project
   py -3.9 -m venv .venv                    # 首次创建 / 丢失时重建（已存在可跳过）
   .\.venv\Scripts\Activate.ps1             # 激活项目 venv，之后统一用 python
   python -m pip install -r tools\requirements.txt
   ```

   之后运行脚本：先激活 `.venv`，再直接 `python xxx.py`。
   激活报"禁止运行脚本"时，先执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

2. **Mosquitto（Windows）** 安装后编辑 `mosquitto.conf`：

   ```
   listener 1883 0.0.0.0
   allow_anonymous true
   ```

   重启服务（services.msc 或 `net stop/start mosquitto`）；防火墙放行 1883（专用网络）。

3. **烧录工具与驱动**：`D:\DevTools_Hi3861V100_v1.0\burntool\BurnTool.exe`；CH340 驱动在
   `D:\DevTools_Hi3861V100_v1.0\usb_serial_driver`。

4. 记录 **PC 在路由器下的局域网 IP**：填入 `firmware\include\app_config.h` 的
   `APP_MQTT_BROKER_IP`，以及 `tools\config.yaml` 的 `mqtt.broker`（两处一致）。

## 1. 硬件接线

| TTL-RS485 转换模块 | 普中板排针 | 说明 |
| --- | --- | --- |
| DI（TXD 输入） | IO0 | 板子 UART1_TXD |
| RO（RXD 输出） | IO1 | 板子 UART1_RXD |
| VCC / GND | 3.3V / GND | 必须共地 |
| A / B | ↔ PC 端 USB-RS485 的 A/B | 不可接反；长距离加 120Ω 终端电阻 |
| DE+RE（若模块带，需并联） | IO8 | 并在 `app_config.h` 启用 `APP_RS485_DE_PIN` 宏后重新编译 |

注意：烧录与日志固定在 UART0（IO3/IO4，板载 CH340，115200 8N1），IO0/IO1 不得再作他用。
无 RS485 模块时，可先用 USB-TTL 直连 IO0/IO1 做串口回环，提前验证第 3 步。

## 2. 编译前配置

## 4. 常见问题排查

- 读不到数据：A/B 接反、COM 口被其它软件占用、双方波特率/校验不一致、未共地
- MQTT 连不上：broker IP 填错、Mosquitto 未监听 0.0.0.0、防火墙拦截 1883
- 扫描不到热点：手机热点需切 **2.4GHz**（Hi3861 不支持 5GHz；iPhone 打开"最大兼容性"）
- `KERNEL PANIC: task stack overflow`：ProjectTask 栈需 ≥10KB（Wi-Fi/MQTT 调用链较深，参考普中 wifi/mqtt demo）
- monitor.py 后台运行无输出：已启用行缓冲；手动调试可加 `-u` 运行

## 6. 运维看板与模拟数据源

周期心跳上线后，**测试无需再按 RST 重放**：设备每 ~15s 自动上报心跳（实测 15~25s，受 Modbus 空转轮询耗时影响；`APP_HEARTBEAT_S` 可调）。

```powershell
.\.venv\Scripts\Activate.ps1

# 中央运维系统终端看板（实时刷新，Ctrl+C 退出；--snapshot N 输出一帧快照便于脚本化验收）
python tools\ops\ops_console.py
python tools\ops\ops_console.py --snapshot 10

# 模拟板卡数据源（无板 / 无 485 演示；--alarm 第 8 秒起触发温度告警）
python tools\sim\sim_device.py --duration 60 --alarm
```

看板内容：设备表（IP / 心跳 / 在线状态）、点位表（原始值 / 工程量 / 告警）、最近消息流；
离线判定为 60s 未收到设备消息。轻量订阅工具 `tools\mqtt\monitor.py` 仍可用于快速查看原始报文。
