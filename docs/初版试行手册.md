# 初版试行手册（板卡到货后照此执行）

> 目标链路：PC Modbus 从站 ⇄ RS485 ⇄ Hi3861（OpenHarmony） ⇄ Wi-Fi/MQTT ⇄ 本机看板。
> 相关文档：`协议适配指南.md`、`寄存器映射表.md`、`../补充说明.md`（工程外改动与构建注意）。

## 0. 一次性准备（到货前完成）

1. **PC 侧环境 = 项目专属 venv**（Python 3.9，位于 `src\project\.venv`，不入 git）：

   ```powershell
   cd D:\hi3861_hdu_iot_application\src\project
   & .\.venv\Scripts\python.exe -m pip install -r tools\requirements.txt
   ```

   之后运行脚本统一用 `..\.venv\Scripts\python.exe xxx.py`（或先激活 `.venv`）。
   venv 丢失时重建：`py -3.9 -m venv .venv` 后重复上面的安装命令。

2. **Mosquitto（Windows）** 安装后编辑 `mosquitto.conf`：

   ```
   listener 1883 0.0.0.0
   allow_anonymous true
   ```

   重启服务（services.msc 或 `net stop/start mosquitto`）；防火墙放行 1883（专用网络）。

3. **烧录工具与驱动**：`D:\DevTools_Hi3861V100_v1.0\burntool\BurnTool.exe`；CH340 驱动在
   `D:\DevTools_Hi3861V100_v1.0\usb_serial_driver`。

4. 记录 **PC 在路由器下的局域网 IP**：填入 `firmware\include\app_config.h` 的
   `APP_MQTT_BROKER_IP`，以及 `tools\config.yaml` 的 `mqtt.broker`（两处一致）。

## 1. 硬件接线

| TTL-RS485 转换模块 | 普中板排针 | 说明 |
| --- | --- | --- |
| DI（TXD 输入） | IO0 | 板子 UART1_TXD |
| RO（RXD 输出） | IO1 | 板子 UART1_RXD |
| VCC / GND | 3.3V / GND | 必须共地 |
| A / B | ↔ PC 端 USB-RS485 的 A/B | 不可接反；长距离加 120Ω 终端电阻 |
| DE+RE（若模块带，需并联） | IO8 | 并在 `app_config.h` 启用 `APP_RS485_DE_PIN` 宏后重新编译 |

注意：烧录与日志固定在 UART0（IO3/IO4，板载 CH340，115200 8N1），IO0/IO1 不得再作他用。
无 RS485 模块时，可先用 USB-TTL 直连 IO0/IO1 做串口回环，提前验证第 3 步。

## 2. 编译前配置

- `firmware\include\app_config.h`：`APP_WIFI_SSID` / `APP_WIFI_PASSWORD` / `APP_MQTT_BROKER_IP`
- `tools\config.yaml`：`serial.port`（USB-RS485 的 COM 口，设备管理器确认）、`mqtt.broker`

## 3. Day-1 步骤与验收

| # | 操作 | 验收标准 |
| --- | --- | --- |
| 1 | 安装 CH340 驱动并插板 | 设备管理器出现 `USB-SERIAL CH340 (COMx)` |
| 2 | `hb set` 选择普中产品（见补充说明 §4）→ Clean+Build → BurnTool 烧录（921600，烧完先 Disconnect 再开串口） | 烧录完成无报错 |
| 3 | 串口助手 115200 8N1 看日志（可不接 RS485） | 出现 `[project] device=普中演示从站 v1 protocol=modbus-rtu points=3` 与 `wifi connected, ip=...` |
| 4 | Wi-Fi 未连时核对 SSID/密码与 2.4G 频段 | 日志出现板子 IP |
| 5 | PC 起模拟器：`..\.venv\Scripts\python.exe tools\modbus_sim\slave_rtu.py` | 打印 `serving RTU on COMx`，无异常栈 |
| 6 | 观察板子串口 | 无读超时刷屏（联调成功后每 1s 一轮） |
| 7 | PC 起看板：`..\.venv\Scripts\python.exe tools\mqtt\monitor.py` | 每秒收到 3 条 JSON（温度/湿度/状态） |
| 8 | 演示告警：改 `tools\config.yaml` 的 `initial_values[0]` 为 850 后重启模拟器 | monitor.py 打印 `[ALARM]`，板子串口出现 alarm 日志 |
